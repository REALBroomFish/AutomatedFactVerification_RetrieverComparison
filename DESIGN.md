# Project Plan

## Input

A single AVeriTeC claim.

## Process

The system will then look at the documents available from the AVeriTeC knowledge base, and compare candidates

## Output

The output will be a ranked list of candidate evidence passages, for each candidate it will return:

1. claim id
2. passage id
3. source urls
4. passage text
5. retrieval score
6. rank

## Success Criteria

Relevant source material should appear near the top of the ranking. The first data walkthrough will determine how annotated AVeriTeC evidence can be mapped to passages reliably.
